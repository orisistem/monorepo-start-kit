# Documentation and Management (`docs/`)

This directory is the central hub for all non-code artifacts required to run the software development company smoothly.

## First Time Here?

- **New to the project?** → Start at [`00-onboarding.md`](00-onboarding.md)
- **Not sure what to read?** → Use the decision index at [`INDEX.md`](INDEX.md)
- **Want the full AI workflow plan?** → [`10-ai-workflow/12-workflow-plan.md`](10-ai-workflow/12-workflow-plan.md)

## Structure

- **`00-onboarding.md`**: First-day guide for developers, tech leads, and AI agents.
- **`INDEX.md`**: Decision index — "what to read when" organized by task, phase, role, and artifact.
- **`01-requirements/`**: Business requirements, PRDs (Product Requirements Documents), user stories (use `PRD-template.md` as starting point for AI-assisted spec generation).
- **`02-planning/`**: Roadmaps, sprint plans, resource allocation.
- **`03-architecture/`**: C4 models, ER diagrams, ADRs (Architecture Decision Records) — use `ADR-template.md`, technical specifications — use `tech-spec-template.md`.
- **`04-api/`**: OpenAPI/Swagger specs, Postman collections.
- **`05-manuals/`**: Runbooks, user guides, admin manuals, bug report template.
- **`06-meetings/`**: Minutes from daily stand-ups, planning, and retrospectives.
- **`07-monitoring/`**: SLA/SLO/SLI definitions, dashboard docs, alerting rules.
- **`08-workflow/`**: Git workflow, Conventional Commits, branching strategy.
- **`09-testing/`**: Testing strategy and pyramid (unit, integration, e2e).
- **`10-ai-workflow/`**: AI-assisted development workflow — guidelines, prompts, and best practices for using AI tools (OpenCode, Antigravity, Claude Code) throughout the project lifecycle.
